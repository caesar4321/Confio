# cUSD conversion fee test plan

Generated by `/plan-eng-review` on 2026-08-29.

Primary design: `docs/plans/cusd-conversion-fee-system.md`

## Affected screens and entry points

- Top Up: exact gross, Confío fee, provider fee, and net cUSD/cUSD+.
- Sell/Withdraw: gross Confío dollars, conversion fee, net USDT, and fiat estimate.
- Direct USDT receive: automatic conversion and pending-below-$1 state.
- Direct external withdrawal: permissionless contract redemption with fee.
- Friend Send: all four eligible/ineligible routing combinations.
- Friend Send compatibility: any sender to a recipient without a recorded fee-capable build.
- Home/portfolio: combined cUSD, cUSD+, and transient pending USDT.
- Transaction detail/receipt/history: exact fee and canonical asset identity.
- Emergency Exit: cUSD, cUSD+, pending USDT, pause, IM failure, and fallbacks.
- Ondo stocks: sponsored app buy/sell through cUSD+ at exactly 30 bps, plus a
  contract-only permissionless stock-to-raw-USDT redemption for an advanced
  caller. The raw selector must not appear in the app or server allowlist.

## Key interactions

- New build completes ramp and direct entry with the same 90 bps fee.
- New build creates an off-ramp order for net USDT and funds it atomically.
- Old build completes Top Up and Sell with the same 90 bps fee despite its stale `Comisión de Confío — Gratis` label.
- Old Sell input is treated as gross debit; the server creates and atomically funds the provider order for the contract-previewed net amount without underfunding.
- Eligible users wrap/unwrap cUSD and cUSD+ without a fee only through a sponsor.
- Outdated recipients receive cUSD+ and remain able to use the old Emergency Exit; an ineligible recipient normalizes to cUSD after updating.
- Permissionless cUSD and cUSD+ redemption always charges the fee.
- Confío stock buy and sell remain sponsor-origin-gated and use only the
  cUSD+ settlement path. The independent `sellToUsdt` contract selector is
  sponsor-independent and charges exactly 30 bps.
- Repeated foregrounds do not duplicate a conversion or sponsor transaction.
- Sub-$1 deposits aggregate and convert once the total reaches the threshold.

## Edge cases

- 1 wei, fee-rounding boundary values, exactly $1, and maximum supported amount.
- Fee lowered between display and prepare; fee changed between prepare and submit.
- Missing/malformed platform and build headers select legacy-compatible amount semantics without waiving the fee or blocking conversion.
- User closes the app after prepare, signature, broadcast, and chain settlement.
- Sponsor timeout with executed, reverted, noop, and unknown outcomes.
- cUSD or cUSD+ globally paused.
- Oracle guard, Instant Manager failure, or insufficient minimum output.
- Provider order returns a deposit amount/address different from the prepared net.
- Existing holder upgraded in place with unchanged share balance and value.
- Existing Stock Router proxy upgraded in place with unchanged owner, accrued
  fees, pause state, immutable dependencies, and fixed 30 bps fee.
- Recipient build capability is missing, stale, recorded on another device, or becomes fee-capable after receipt.
- Emergency destination cannot accept or redeem raw cUSD+.

## Critical paths

- External USDT -> cUSD -> cUSD+ -> cUSD -> external USDT.
- Koywe/Infinia fiat entry -> USDT -> cUSD/cUSD+ -> provider net settlement -> fiat.
- Eligible sender -> ineligible recipient and the inverse direction.
- New-build sender -> old-build recipient -> old Emergency Exit -> post-update normalization.
- Existing cUSD+ proxy upgrade and rollback on a BSC mainnet fork.
- Existing Stock Router proxy upgrade on a BSC mainnet fork; sponsored app
  selectors remain gated and the advanced raw-USDT selector remains directly
  reachable without Confío sponsorship.
- Server unavailable -> installed app Emergency Exit -> public RPC -> net USDT or raw-token fallback.
